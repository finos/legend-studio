# Legend Query

Legend Query is where you query the data a Legend model describes, without writing code. You pick a data space, which
is what a model offers the people who use its data. Then you drag the properties you want from its classes, and run
the query: the engine runs it on the store that holds the data, such as a database. You can save a query to open it
again later or share it.
