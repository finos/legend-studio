# Legend Studio

Legend Studio is where you write and change a Legend project: its models, the mappings that connect them to data, the
connections and runtimes those use, and the services, tests and diagrams built on them. The SDLC server keeps each
project in a GitLab repository. You change a project in a workspace, your own copy of it, then push your changes,
review them, and release a version that other projects and applications can use.
