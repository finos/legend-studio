# Release Review: 13.266.0 to 13.269.0

The changes that shipped after 13.265.0, up to and including 13.269.0, ranked by risk, riskiest first.

## Scope

- The release numbers are those of the deployment packages. Studio, Query and Marketplace share one version line.
- 13.265.0 is `90092c645` ([#5586](https://github.com/finos/legend-studio/pull/5586)) and 13.269.0 is `b10f82d0c` ([#5646](https://github.com/finos/legend-studio/pull/5646)).
- 39 PRs merged between those two commits, across four releases (13.266.0 to 13.269.0).
- [#5671](https://github.com/finos/legend-studio/pull/5671) and everything after it shipped after 13.269.0, so they are not included.
