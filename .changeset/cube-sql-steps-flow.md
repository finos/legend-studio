A definition's flow draws the engine's SQL island, `#SQL{…}#`, as a container of the steps its SQL says, its sources then its clauses in the order they run, when the host gives the engine's tree of the SQL (`getSqlTree`, for the SQL `findCubeDefinitionSql` lists). Cube checks none of the clauses. Without a tree, or with SQL Cube has no steps for, the island stays one box. The note for the steps after SQL no longer says SQL is one step.
