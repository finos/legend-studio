Fix inputs and labels that were unreadable or off-theme in the light and dark themes. Enumeration value inputs and profile tag and stereotype inputs now use the theme's input colors instead of the browser's white box. In the database editor, primary keys, foreign keys and schema names keep their yellow, blue and purple but use a shade per theme. Counts, nullable columns and join formulas use muted text instead of disabled text. The diagram's edge labels and minimap follow the theme.
