`QueryBuilderWorkflowState` gains three options, each on by default, for a workflow that embeds the query builder for a part of a query, as Legend Cube's data space source does: `showHeaderMenus` (the Advanced and Help menus), `showProjectionAggregation` (a column's aggregate operator) and `showQueryOptions` (sort, distinct, limit and dates).
