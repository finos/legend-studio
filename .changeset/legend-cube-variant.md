Legend Cube shows a Variant (JSON) cell on one line, `{name: ann, tags: [a, b]}`, numbers as written, and its menu's Open JSON shows the document as a tree, with Copy JSON (PLAN §11.20). Explore JSON… on a Variant column (its cells' and its header's menu) reads its first 1,000 values, or every row, through Runs, shows its fields with their kinds and shares, and adds the columns ticked from each field's offers (the value typed, as JSON, keys, counts, lists, contains, the first element's fields, totals) as one Extend. The core gains `getVariantDatabaseProblem`: JSON is read on Snowflake, Databricks, Postgres and DuckDB. A text cell holding a JSON object or array offers Parse as JSON (`fromJson()`), and the DuckDB Sales sample gains a table of orders as JSON documents, with the example Orders from JSON; an example now runs once its Extend is typed.
