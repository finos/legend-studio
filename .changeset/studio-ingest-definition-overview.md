The ingest definition editor's Definition tab opens on an Overview: a Definition section with the definition's main settings, the rest one click away, then its materialized views and data sets. A data set shows its Schema or its Metadata, a view its Flow or its Metadata, and a definition with no views opens on the Overview too. Once the documentation registry has entries for them, a help icon beside Overview | Pure opens the Legend Studio guide's page on ingest definitions (`dsl-ingest.concept.element.ingest-definition`), and one in Legend Cube's header, while it builds or edits a materialized view, opens its section on building a view (`dsl-ingest.concept.element.materialized-view`).
