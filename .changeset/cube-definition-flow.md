A read-only definition flow for hosts: `@finos/legend-cube-builder/definition-flow` reads a data product's access point definition (its lambda's protocol JSON) into Cube's steps with no engine, the ingest data sets typed from their definitions' JSON, and draws them on an embedded canvas with no step editor, menu, palette or minimap; a click on a step tells the host. Each refusal of a lambda now has a kind a host can count (`CubeLambdaReadErrorKind`: parameters, shape, value, source, no step, not yet, form, same-name sum), with the function it names. Read to be drawn, a group may name a sum like the column it adds up, as Pure allows; the editor still refuses it, and now says why. A data set whose columns aren't known shows its name. Each step keeps the relation it was read from.
