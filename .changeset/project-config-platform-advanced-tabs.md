Project configuration: the Platform Configurations and Advanced tabs are laid out as form sections, like the project structure tab. Platform versions are either the latest or frozen, chosen with two labelled options; each frozen version shows its own status and can be moved to the latest version on its own, and versions entered by hand only apply when frozen (Cancel drops them). The Advanced tab shows dependency tests as a labelled checkbox and the project type as Managed and Embedded cards with the current one marked; changing the type says that it is saved straight away. Every control there is disabled in viewer mode.
