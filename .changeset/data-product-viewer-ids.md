The data product viewer shows IDs next to the titles, and one click copies an ID: beside the title, the deployed data product ID and the deployment ID (DID), which move under it when a long title leaves no room; after each access point group and access point title, its ID. An ID that the title already shows is not repeated, and the header shows no IDs without a deployment (as in Studio's preview). A description that only repeats its title (ignoring case and spacing) is no longer shown, for the data product, its access point groups and its access points. Access point groups no longer show the LAKEHOUSE badge: it was the same on every group.
